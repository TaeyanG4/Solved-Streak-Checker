# Chrome 웹 스토어 등록 자료 (v2.0.0)

개발자 대시보드(https://chrome.google.com/webstore/devconsole)의 기존 항목에 새 패키지를 올릴 때 쓰는 자료입니다.

## 1. 패키지

- 파일: `dist/solved-streak-checker-2.0.0.zip` (`npm run package`로 만들고, 안의 파일이 작업 트리와 같은지 확인)
- 버전: 2.0.0 (이전 버전 1.0.2보다 높아야 업로드됨)
- 최소 Chrome 버전: 116

## 2. 스토어 등록정보

- **이름**: Solved Streak Checker
- **요약**(manifest `description`, 72자): solved.ac 공식 API로 스트릭을 확인하고, 오늘 문제를 풀지 않았다면 마감(오전 6시) 전에 알려줍니다. (비공식 확장)
- **카테고리**: 생산성
- **언어**: 한국어

### 상세 설명

```
solved.ac 스트릭을 지키도록 도와주는 비공식 확장 프로그램입니다.

■ 주요 기능
• solved.ac 공식 API(v4)로 오늘 문제를 풀었는지 자동으로 확인해요(확인 주기 1~1440분).
• 툴바 배지로 한눈에: ✓ 오늘 해결 · ! 아직 안 풂 · 휴 스트릭 휴가 · ? 확인 불가
• 팝업: 현재/최장 스트릭, 오늘 푼 문제 수, 최근 7일 기록(스트릭 프리즈 포함), 마감까지 남은 시간
• 오늘 안 풀었으면 마감(오전 6시, 한국 시간) 전에 알림. 알림 시작 시각과 다시 알림 간격을 고르고, "오늘은 그만 알림"으로 그날 알림을 끌 수 있어요.
• 백준에서 푼 기록이 늦게 반영되면 "채점 사이트에서 다시 불러오기"로 solved.ac 연동 설정을 열고, 반영될 때까지 잠깐 더 자주 확인해요.
• solved.ac의 하루 기준(오전 6시)·서버 시계 보정·스트릭 휴가와 프리즈를 그대로 따르고, 다크 모드를 지원해요.

■ 시작하기
1. solved.ac Backstage(https://backstage.solved.ac/developer/apps)에서 앱을 만들어 클라이언트 ID와 시크릿을 받아요(무료).
2. 확장 프로그램 설정에 solved.ac 핸들과 클라이언트 ID/시크릿을 넣고 저장하면 바로 확인을 시작해요.

■ 개인정보
• 핸들과 알림 설정은 Chrome 동기화 저장소에, API 키와 확인 기록은 이 기기에만 저장해요.
• solved.ac API 말고는 어디로도 데이터를 보내지 않고, 광고나 분석 도구를 쓰지 않아요.
• 설정의 "모든 데이터 지우기"로 언제든 지울 수 있어요.

solved.ac의 공식 확장 프로그램이 아니며, solved.ac API를 이용합니다.
```

## 3. 개인정보 보호 관행 탭

- **단일 목적**: solved.ac 사용자의 스트릭(오늘 문제를 풀었는지)을 확인해 툴바 배지와 데스크톱 알림으로 알려 주는 것.
- **권한 사유**
  - `alarms`: 설정한 확인 주기, 하루 경계(오전 6시 KST), 다시 알림 시각에 확인하고 알림을 띄우기 위해.
  - `notifications`: 오늘 문제를 풀지 않았거나 확인에 문제가 생겼을 때 데스크톱 알림을 띄우기 위해.
  - `storage`: 핸들·알림 설정(동기화)과 API 키·마지막 확인 결과(이 기기)를 저장하기 위해.
  - 호스트 권한 `https://solved.ac/*`: solved.ac 공식 API(`https://solved.ac/api/v4/...`)에 스트릭 정보를 요청하고, 사용자가 solved.ac 페이지를 열었을 때 바로 다시 확인하기 위해. 콘텐츠 스크립트는 페이지 내용을 읽지 않고 방문 사실만 알립니다.
    - v1(1.0.2)은 `https://solved.ac/profile/*`였습니다. 새 solved.ac는 프로필 주소가 `/u/핸들`로 바뀌었고 API가 `/api/v4/`에 있어 범위를 넓혔습니다(두 경우 모두 Chrome의 경고 문구는 "solved.ac의 데이터 읽기 및 변경"으로 같습니다).
- **원격 코드 사용**: 아니요(모든 코드는 패키지에 포함, CSP `script-src 'self'`).
- **데이터 사용 공개**
  - 개인 식별 정보: 예 — solved.ac 핸들(공개 사용자 이름). 스트릭 조회에만 사용.
  - 인증 정보: 예 — 사용자가 직접 발급한 solved.ac API 클라이언트 ID·시크릿. 이 기기에만 저장하고 solved.ac API 요청 헤더로만 보냄.
  - 그 밖의 항목(건강, 금융, 개인 커뮤니케이션, 위치, 웹 기록, 사용자 활동, 웹사이트 콘텐츠): 아니요.
  - 세 가지 확인란 모두 체크: 승인된 용도 외 제3자 판매 안 함 / 단일 목적과 무관한 용도로 사용·전송 안 함 / 신용도 판단·대출 목적 사용 안 함.
- **개인정보처리방침 URL**: https://github.com/TaeyanG4/Solved-Streak-Checker/blob/main/PRIVACY.md (푸시한 뒤 열리는지 확인)

## 5. 대시보드에서 하는 일(직접)

Chrome은 확장 프로그램이 웹 스토어 페이지를 조작하지 못하게 막으므로, 아래는 직접 합니다.

1. https://chrome.google.com/webstore/devconsole 에서 **Solved Streak Checker** 항목을 엽니다.
2. **패키지** → **새 패키지 업로드** → `dist/solved-streak-checker-2.0.0.zip`
3. **스토어 등록정보**: 위 2의 상세 설명을 붙여넣고 카테고리·언어 확인. 그래픽에서 예전 스크린샷을 지우고 `store/`의 스크린샷 5장과 작은 프로모션 타일을 올립니다.
4. **개인정보 보호 관행**: 위 3의 단일 목적, 권한 사유(4가지), 원격 코드 "아니요", 데이터 사용(개인 식별 정보·인증 정보), 확인란 3개, 개인정보처리방침 URL.
5. **저장** → **검토를 위해 제출**. 검토 중 권한 범위(`/profile/*` → `/*`)에 대한 질문이 오면 위 3의 설명을 씁니다.
